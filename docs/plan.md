# 여덟 글자: 기획서 v1

작성 2026-11-07. 배포 실습 앱 2번. 디자인 시안(휴대폰 넷 + PC 하나) `../디자인/여덟글자_시안.html`

## 한 줄

> 태어난 날과 시를 넣으면 내 사주 여덟 글자와 오행의 균형을 보여 주고, 오늘의 기운을 한 장 카드로 건넨다. 계산은 코드가, 풀이는 문장이.

## 왜 지금

- 운세 앱 이용자 중 2030 비중이 57~66%(모바일인덱스 재인용)
- 사주 특화 GPT 상위 셋의 누적 이용자 300만, 200만, 90만. 같은 기간 대표 운세 앱 월간 이용자는 113만에서 87.5만으로 줄었다
- 이용 동기는 정확도보다 위로와 생각 정리(뉴시스 2026-08)
- 업계 권고: "만세력 계산은 직접, 풀이만 AI". 계산이 틀리면 풀이가 아무리 그럴듯해도 틀린다
- 강의와 맞는 점: 숫자는 규칙(코드), 판단과 문장은 AI. 선택 과제로 환경 변수와 서버 함수를 배운다

## 누가, 언제

| 사용자 | 순간 | 바라는 것 |
|---|---|---|
| 2030, 사주를 재미로 보는 사람 | 새해, 이직이나 시험 전, 자기 전 | 내 여덟 글자가 무엇인지, 무엇이 많고 적은지 한눈에 |
| 친구와 비교하는 사람 | 단톡방 | 카드 한 장을 보내고 "너는 뭐 나와?" |

## 1분 흐름

```
첫 화면 → 생년월일, 태어난 시(모르면 '모름'), 양력/음력 → 보기
   → 여덟 글자 표(년, 월, 일, 시 × 천간, 지지) → 오행 다섯 막대(목, 화, 토, 금, 수)
   → 나의 일간 한 줄(예: '큰 나무 같은 사람') → 오늘의 기운(오늘 일진과 나의 관계) → 카드 저장
```

## 화면

| 화면 | 하는 일 | 핵심 요소 |
|---|---|---|
| 1 입력 | 날짜, 시, 양력/음력 | 휠 선택(년, 월, 일), 시는 12지 시간대 버튼과 '모름', 안내 "입력은 이 기기에서만 계산" |
| 2 여덟 글자 | 표 보기 | 4기둥 × 2글자, 한자와 한글 음, 오행 색, 일간 강조 |
| 3 오행 | 균형 보기 | 다섯 막대(개수), 많은 것과 비어 있는 것 한 줄 |
| 4 오늘 | 오늘의 기운 | 오늘 일진의 천간과 나의 일간 관계(생, 극, 같음) 다섯 가지 중 하나의 문장, 행운의 색 |
| 5 카드 | 공유 | 1080×1350 카드: 여덟 글자, 오행 막대, 한 줄. 저장, 공유 |

## PC 화면 (반응형)

- 1280px 이상: 왼쪽 칸에 입력, 오른쪽 칸에 결과(여덟 글자 표, 오행 막대, 나와 오늘)를 한 화면에. 입력을 바꾸면 결과가 바로 바뀐다
- 공유 카드 미리보기는 오른쪽 아래 작은 카드로, 저장 버튼 옆에
- 날짜 입력은 PC에서 키보드로 바로 칠 수 있는 칸(YYYY-MM-DD), 휴대폰에서는 휠 선택
- 768~1279px: 입력 위, 결과 아래 한 칸

## 데이터와 계산

- 엔진: lunar-javascript 1.7.8(MIT, 파일 하나 437KB, 오프라인). 년주는 입춘, 월주는 절입 시각 기준
- 음력 입력: korean-lunar-calendar 0.4.0(MIT, 18KB, 한국천문연구원 기준, 2050년까지)으로 양력 변환 뒤 엔진에 넣는다(한국과 중국 음력이 다른 날이 있어서)
- 시간 보정: 절기 시각이 북경 시간(UTC+8) 기준이라, 입력 시각을 진태양시로 보정(서울 약 -32분)해서 넣는다. 1954~61년 표준시(UTC+8:30), 1948~51, 1955~60, 1987~88년 서머타임 기간 출생자는 안내 문구를 띄운다
- 야자시: 기본은 23시 이후에도 그날 일주 유지. 화면에 기준을 한 줄로 밝힌다
- `data.js`(고쳐 보는 곳): 일간 열 가지 한 줄, 오행 다섯 설명, 오늘의 기운 다섯 문장, 행운의 색
- 정답 점검: 이름난 만세력과 생일 10개를 대조하는 `check.html`(개발용, 배포에서 숨김)

## 기술

- 파일: index.html, style.css, app.js, data.js, lib/lunar.js, lib/korean-lunar-calendar.min.js, og.png, README.md
- 선택 과제: `api/풀이.js` 서버 함수 하나. 사주 표(여덟 글자와 오행 개수)만 보내고 생년월일은 보내지 않는다. 키(`OPENAI_API_KEY` 또는 `ANTHROPIC_API_KEY`)가 없거나 실패하면 data.js 문장으로 대체
- 환경 변수는 바꾼 뒤 다시 배포해야 반영(가장 많이 막히는 곳). 공개 주소라 남용 대비로 하루 호출 수 제한 안내

## 디자인 방향

- 톤: 한지와 먹, 오방색. 밝은 미색 바탕, 오행 다섯 색(목 청록, 화 주홍, 토 황토, 금 은회색, 수 남색)은 오행 표시에만
- 글꼴: 한자와 제목은 명조, 본문은 Pretendard. 한자 옆에 한글 음을 늘 같이
- 표는 네 기둥이 세로로 서는 전통 배치(오른쪽이 년주)를 따르되, 처음 보는 사람을 위해 기둥 이름을 위에 적는다
- 레퍼런스 앱의 캐릭터, 색 조합을 쓰지 않는다

## 배포 실습 포인트

1. lib/ 폴더까지 함께 올라가야 계산이 된다(폴더째 업로드의 의미)
2. `data.js`의 일간 한 줄을 내 말투로 바꿔 푸시
3. 선택: Vercel 환경 변수에 키를 넣고 다시 배포 → AI 풀이 켜짐. 키를 빼면 문장 풀이로 돌아오는 것까지 확인

## 위험과 표현

- 재미와 참고용이라는 안내를 첫 화면과 카드에
- 단정, 불안 조장 금지: "~할 운명", 질병, 사고, 사망, 이별 예언 없음. 성향과 균형의 언어로
- 생년월일시는 기기 안에서만 계산. AI 풀이를 켜도 서버에는 여덟 글자와 오행 개수만
- 만 14세 미만 이용 안내(개인정보를 받지 않으므로 동의 절차는 없지만 표현 수위는 전체 이용가)
