# 여덟 글자 AI 풀이: 골과 운영 기준

작성 2026-11-08. 사용자 요청: OpenAI 키로 가성비 모델을 붙이고, 사주 풀이 앱으로 실제 운영 가능한 수준까지.

## 골 한 문장

> 공개 주소에 올려 아무나 써도 비용과 표현이 통제되고, 만세력 계산 위에서 읽을 만한 풀이를 10초 안에 건네는 사주 앱.

## 원칙

1. **계산은 코드, 풀이는 AI.** 네 기둥, 오행 개수, 십성(나와 다른 글자의 관계)은 `saju.js`가 계산해 보낸다. AI는 계산하지 않고 해석만 한다
2. **생년월일은 보내지 않는다.** 서버로 가는 것은 여덟 글자, 오행 개수, 십성, 오늘 일진뿐. 자유 입력 글도 보내지 않아 프롬프트 주입 통로가 없다
3. **실패해도 화면은 멈추지 않는다.** 키가 없거나, 서버가 없거나, 시간이 넘거나, 표현 점검에 걸리면 data.js 기본 풀이로 돌아간다
4. **비용은 위에서 막는다.** 같은 사주와 같은 날은 다시 부르지 않고(브라우저와 서버 양쪽 저장), 한 사람이 너무 자주 부르면 막고, 하루 상한을 둔다. 월 상한은 OpenAI 대시보드 예산으로
5. **표현은 두 번 거른다.** 지시문에서 금지하고, 받은 글을 금지어로 한 번 더 확인한다. 걸리면 한 번 다시 쓰게 하고, 또 걸리면 기본 풀이로

## 모델과 비용

| 항목 | 값 |
|---|---|
| 모델 | `gpt-5.6-luna` (환경 변수 `OPENAI_MODEL`로 바꿈) |
| 단가 | 1M 토큰당 입력 0.2달러, 출력 1.2달러 (공시 데스크 기준값) |
| 방식 | chat/completions, JSON 스키마(strict), reasoning_effort low |
| 목표 | 한 번 풀이 3원 안팎, 10초 안 (시험으로 확인) |

## 풀이 구성 (JSON)

| 칸 | 내용 |
|---|---|
| headline | 한 줄 제목 (30자 안) |
| summary | 전체 인상 2~3문장 |
| sections | 타고난 결, 오행의 균형, 일하는 방식, 사람 사이, 오늘의 흐름 (각 2~4문장) |
| action | 오늘 해 볼 한 가지 (40자 안) |
| keywords | 나를 나타내는 낱말 셋 |

## 운영 장치 (api/reading.js)

| 장치 | 내용 |
|---|---|
| 입력 검증 | 기둥은 간지 두 글자 정규식, 개수는 0~8 정수, 십성은 열 가지 중에서만, 본문 4KB 안 |
| 출처 확인 | `ALLOWED_ORIGINS`를 넣으면 그 주소에서 온 요청만 |
| 호출 제한 | 한 사람(IP) 시간당 20번, 서버 하루 `DAILY_LIMIT`(기본 1,000번). 서버리스라 인스턴스마다 따로 세는 근사치 |
| 저장 | 서버 메모리 24시간, 브라우저 localStorage (같은 사주, 같은 날) |
| 시간 | OpenAI 25초 제한, 429와 5xx는 한 번 다시, `vercel.json` maxDuration 30초 |
| 표현 점검 | 금지어(죽음, 사고, 질병, 이혼, 파산, 액운, 운명 단정 등)에 걸리면 한 번 다시, 그다음은 기본 풀이 |
| 기록 | 토큰 수와 걸린 시간만 서버 로그에. 사주 내용은 남기지 않는다 |

## 완성 기준

- 서로 다른 사주 12개로 실제 호출: JSON 오류 0, 금지어 0, 평균 10초 안, 한 번 3원 안팎
- 핸들러 단위 시험(가짜 OpenAI): 입력 검증, 호출 제한, 표현 점검 재시도, 키 없음, 시간 초과
- 화면: 휴대폰과 PC에서 불러오는 중, 성공, 실패 세 상태 점검 통과
- zip과 GitHub에 키가 들어가지 않는다(.gitignore에서 .env 제외)

## 결과 (2026-11-08)

- 실제 호출 12개(일간 열 가지 고루, 시간 모름 둘, 야자시, 입춘 전, 1950년대 표준시 포함): 성공 12/12, 평균 7.8초, 평균 1.66원, 입력 평균 958 토큰, 출력 평균 831 토큰, 본문 평균 1,042자. 문체 위반("~습니다") 0, 가운뎃점 0, 금지어 0. 샘플은 `docs/ai-samples.md`
- 첫 시험에서 고친 것: 해요체 대신 "~습니다"를 씀, 가운뎃점을 씀, 제목이 "단단함 속에 ~"로 비슷함 -> 지시문에 문체 규칙과 일간의 상징(큰 나무, 원석 등)을 넣고, 후처리로 가운뎃점을 쉼표로, "~습니다"가 둘 이상이면 다시 쓰게 함
- 금지어 오탐 점검: "사고가 유연해요", "희망하는", "불길처럼"은 통과하고 "교통사고", "운명이에요", 한자는 걸림
- 서버 함수 단위 시험(가짜 OpenAI) 20개 모두 맞음: 405, 키 없음 503, 형식 오류 400(십성 자리 주입 포함), 출처 403, 저장, 금지어 다시 쓰기, 두 번 걸리면 502, 500 다시 시도, 429, 401, IP 상한, 하루 상한
- 화면: 휴대폰과 PC, 키 있음(실제 풀이)과 키 없음(기본 풀이) 모두 화면 점검 통과
- 남은 것: 실제 Vercel에서 환경 변수와 maxDuration 확인, 호출 제한을 인스턴스 공용 저장소로 옮길지(사용자가 늘면), OpenAI 대시보드 월 예산 설정
